# 研究简报模板

> 直接复制这份骨架到 `research/<name>.md` 填。QA 脚本按这些小节的编号检查，
> 小节标题**不要改编号**。

```markdown
# 需求研究：<一句话标题>

日期：YYYY-MM-DD ｜ 模式：A / B / C ｜ 素材量：n=<条数>

## 0. 研究模式与输入

- 模式：Mode A（分析已有素材）
- 输入：<文件路径 或 聊天记录范围>
- 为什么用这个模式：<一句>

## 1. 任务与场景

- 买家想办的活：<job，不是 solution>
- 触发场景：<什么时候、为什么现在要>
- 归属商品类别：<products-registry.md 里的编号>

## 2. 客户语言库

| 客户说 | 我们说（不要对外用） |
|---|---|
| … | … |

## 3. 主题（按 频次×强度 排序）

### 主题 1：<名字>（频次 n，强度 4/5）

- 原话：“…”
  - 来源: <文件:行>
- 原话：“…”
  - 来源: <文件:行>
- 意味着：<一句可行动结论>

### 主题 2：…

### 主题 3：…

## 4. 异议与风险

| 异议/风险 | 买家怎么说的 | 应对 |
|---|---|---|
| … | … | … |

## 5. 交付与报价口径

- 交付物：<文件类型 + 份数>
- 价格区间：¥<低>–¥<高>（来源: freelance/shop/pricing.md）
- 工期区间：<天>

## 6. 待确认问题（最多 5 条，一次问完）

1. …

## 7. 来源与置信度

- 样本量：n=… ｜ 置信度：低 / 中 / 高
- 主要来源：<逐条列>
- 不确定的地方：<列出>
```

## 每个小节写什么（一句话版）

| 小节 | 一句话 |
|---|---|
| 0 | 用了哪个模式、喂了什么进去、为什么 |
| 1 | 他要办的活 + 什么时候要 + 属于哪个商品 |
| 2 | 客户原话的词 vs 我们的行业词 |
| 3 | 按 频次×强度 排的主题，每个挂 ≥2 条原话 |
| 4 | 他不买的理由 + 可能翻车的点 |
| 5 | 交什么、多少钱（引 pricing.md）、多久 |
| 6 | 还不确定、要问他什么（≤5 条） |
| 7 | 样本多少、信不信、不确定在哪 |
