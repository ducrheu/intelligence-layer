# 客户语言库（增量维护）

> 只收**真实出现过**的说法。每次做完一项研究，把新出现的客户用词追加到这里。
> 左列是客户的话，写文案时优先用左列；右列是我们的行话，对外不要用。
> 来源：`freelance/style/VOICE.md`、`freelance/shop/products/*.md` 的既有表述，
> 以及历史 job 的 customer request（`freelance/jobs/job_20260911_001/README.md` 等）。

| 客户说 | 我们说（不要对外用） |
|---|---|
| 表太乱 / 看得头大 | 数据质量差 |
| 合并到一起 / 并成一张总表 | 数据集成 |
| 重复的删掉 / 缺的补上 | 去重与缺失值处理 |
| 每个月都要弄一次 | 周期性任务 |
| 看得懂就行 / 别太复杂 | 可维护性 |
| 会不会泄露 | 数据安全合规 |
| 你怎么保证没漏 | 一致性校验 |
| 先发你一份看看 | 提供样例数据 |
| 多少钱、多久能好 | 报价与工期 |

## 使用规则

1. 写商品描述/客服回复时，**优先左列**。出现一次行话就算一次 AI 味信号。
2. 客户用词含混时（如"帮我弄干净"），不要照抄——翻译成明确动作（"去重 + 补缺 + 日期统一"），
   但要保留他的关注点。
3. 新增行必须带出处；没有出处的词不要进这张表。
