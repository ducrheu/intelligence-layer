# 组合选择 / 有效前沿：一份可复用的脚手架（案例）

这是 SKILL.md 方法的一个完整实例。目标是让他能自己推出来。

## 规范型与四个对象

```
w 权重向量(N×1)   μ 期望收益(N×1)   Σ 协方差(N×N)   1 全1向量
min  wᵀΣw              目标：方差（一个二次型）
 s.t. wᵀμ = μ_p , wᵀ1 = 1     两条线性约束（可行时另有 w ≥ 0）
```

N 从 2 到 5000 结构不变，解的形状不变：`w* = Σ⁻¹(λμ + γ1)` 形态。

## 需要的最小工具集（线代 4 件 + 最优化 2 件）

| 工具 | 在课里的落点 |
|---|---|
| 矩阵乘 / 二次型 `wᵀΣw` | 方差就是这个式子 |
| 解线性方程组（不是求逆） | `Σx = b` |
| 二次型求导 `∂(wᵀΣw)/∂w = 2Σw`、`∂(wᵀμ)/∂w = μ` | 推最优性条件 |
| 半正定（→目标凸 → 最小唯一） | 前沿双曲线形状的来源 |

最优化只留：拉格朗日乘子（等式约束）+ KKT（`w ≥ 0`）。乘子就是**影子价格**，有经济含义之后它不再抽象。

**暂缓/删除**：特征值分解、PCA/因子模型、Cholesky、收缩估计、CAPM 推导族、数值最优化内部、Bodie 通读。理由统一是「现在学没有落点」。

## 三级台阶

**台阶 0（零前置，30–60min）**：两只资产纯标量
```
σ_p² = w²σ₁² + (1−w)²σ₂² + 2w(1−w)ρσ₁σ₂
令 dσ_p²/dw = 0  ⇒  w* = (σ₂² − ρσ₁σ₂) / (σ₁² + σ₂² − 2ρσ₁σ₂)
```
顺手画一遍双曲线，并跑一个 ρ = −1 的怪例。

**台阶 1**：三只资产带具体数字，两条约束的两个乘子现场解出（一个 2×2 方程组）。

**台阶 2**：矩阵形式，`Σ⁻¹` 念成「解方程组」。

## 闭式与自检恒等式

```
A = 1ᵀΣ⁻¹μ    B = μᵀΣ⁻¹μ    C = 1ᵀΣ⁻¹1    D = BC − A²
w*(μ_p) = Σ⁻¹[ ((Cμ_p − A)/D)·μ + ((B − Aμ_p)/D)·1 ]
σ_p²(μ_p) = (Cμ_p² − 2Aμ_p + B) / D
```
把 `w*` 代回两条约束必须**精确**成立——这是最便宜的自检，数值上等价于 A/B/C/D 定义的自洽。

### 乘子陷阱（务必并排写）

以 `σ_p² = wᵀΣw`（**不带 ½**）为目标时，`L = wᵀΣw − λ(wᵀμ−μ_p) − γ(wᵀ1−1)`：

```
∂L/∂w = 2Σw − λμ − γ1 = 0  ⇒  w = Σ⁻¹[(λ/2)μ + (γ/2)1]
包络定理           ⇒  λ = ∂σ_p²/∂μ_p        （无 ½）
对照闭式           ⇒  (Cμ_p − A)/D = λ/2     （不是 λ）
```

若改用 `½wᵀΣw` 起步，则 `w = Σ⁻¹(λμ+γ1)` 且 `λ` 正好等于 `(Cμ_p−A)/D`。**两套记法各差一个 2**——混用就会写出「乘子 = ½·∂σ²/∂μ_p」这类错。自检：取 `Σ=[[1,0.3],[0.3,1]]`、`μ=[0.1,0.3]`，在几个 μ_p 上比「拉格朗日解出的 λ」与「中心差分的 ∂σ_p²/∂μ_p」，必须逐点相等。

## 真懂侧检查点

- 台阶 0 后：白纸推 `w*`，含 ρ = −1 怪例。
- 台阶 1 后（**最容易翻车的一关**）：一句话说清乘子的经济含义 + 现场解出两个乘子。三问答不上（含义、怎么被约束定死、为何是全局最小）= 没懂。
- 加第三只资产时，**先猜前沿往哪移再验算**。
- 把 Σ 弄到近奇异，看权重爆炸并解释（只留「Σ 近奇异 ⇒ 权重爆炸」，不要顺手挂接 T<N / 收缩估计）。
- 乘子**双路数值一致**（自动抓公式记错）。
- 区分「给定 μ_p 的最小方差」与「最大夏普/切点」——两者不是一回事。
- 讲给一个不懂的人听，不借助速查表。

## 卷面侧（有闭卷笔试时）

独立并存、必须在掌握侧之外单独过：题量下限、限时成套数（含单套时长/题量下限）、首刷与错题二刷正确率、按「有效前沿 / 组合选择 / 风险度量」分项正确率；范围锁定后**在 72 小时内**出「范围 × 已刷题」对照表，缺口补齐才算可以进考场。

## 排期

这门课若是**学分课**：时间已付过，不算新战线，但闭卷笔试的卷面分是真的，因此仍**给有界配额**（每周 1 次 × 单次 ≤60min × 总量上限，时段从既有时间盒出，不侵占当前主线），并按考试日 D 分档（远/近/极近三档，含「D 前加时」的带条件例外）。上限来源多个时取更严者。
