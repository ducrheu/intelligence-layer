# 量化 / Big Tech / AI 工程：岗位门槛与薪资带（新 / 港 / 沪）

用途：回答「某岗位要什么学历」「某地这行能赚多少」「除了量化还有什么」「读博值不值」。数字均为区间参考，逐年核对。

## 一、岗位阶梯与学历门槛（买方 / 科技）
| 岗位 | 学历门槛 |
|---|---|
| 普通 Data Engineer | 本科 / 硕士 |
| Quant Developer / 研究平台工程 / 数据工程 | 本科 / 硕士（**博士很少被要求**；「无高学历者最常用的入口」）|
| Quant Execution / Strategy Researcher | PhD **或** Master's |
| 卖方/大行 quant、risk | 硕士 |
| ML Researcher / Quant Researcher（Citadel / Two Sigma / RenTec / DE Shaw）| **卡博士** |
| Jane Street 研究 | 官方称**多数研究员无博士** |
| Quant Trader（做市/自营 Jump / Optiver / IMC）| 学历非硬门槛，但**画像高度集中 IMO 奖牌 + 顶校** |

- 面试权重：QD ≈ 70% 编程/系统 + 30% 数学；Trader ≈ 概率 + 心算 + 市场博弈（**可训练、见效快**）。
- 顶级公司录取率 <1%；简历筛只看具体信号（量化学位 / 竞赛牌 / 买方实习 / 有分量的项目 / 开源）。
- **表格里「卡博士」和「或」是两种不同的门**：同一条梯子上常并存两条入口线。读 JD 时按入口分开读，别把「或」字当成「博士不必要」。

## 三、各地区薪资带（2026 样本）
**新加坡**
- Big Tech：Google L3 S$155k / **L5 S$254k / L6 S$447k**；ByteDance 3-1 S$273k（3-2 至 S$427k）。

## 三·补：新加坡 vs 香港 —— 先归一，再比

**别凭印象比大小。** 一地说「比另一地高 4%」、同时说「比纽约低 15%」，两个事实混着讲会变成一句错的结论「某地市场更好」。归一到一个指数（枢纽城市 = 100）之后，量级关系立刻清楚。

- **薪酬指数（纽约 = 100）**：新加坡 **82**，香港 **85**。
  → 香港高约 **3.7%**；而香港到纽约还要 **+17.6%**。**换城市拿到的，只有「再上一级」的约 1/5。**
- **招聘指数排名**：新加坡 **#4 / 17**，香港 #5 / 17，两地都被评为 very strong ——**不是一大一小**。别用「某地岗位池小得多」这种不可核实的印象句。
- 薪酬对照（base + 预期奖金，美元计）：量化研究员 新 S$522k / 港 ≈ $404k；量化交易员 新 S$494k / 港 ≈ $383k；系统化 PM 新 S$1.4m / 港 ≈ $1.1m。
- **两地都是分部，上限都不是它们定的，是枢纽（纽约/伦敦）定的。** 所以「A 地上限更高吗」如果指绝对上限，答案是「都不是」。

**真正的结构差异是策略方向，不是薪酬：**
- **中国相关（股票 / 衍生品 / 中概）→ 香港有不可替代性**：靠近内地市场、普通话 + 在岸市场知识有溢价。做这条线，香港不是「高 3.7%」的问题，是**该赛道在别处不全**。
- **系统化交易 / 商品 / 宏观 / 量化研究 → 新加坡更全**，另有增长中的 crypto 与数字资产板块。

**「哪些公司在哪座城市有岗」比「哪个市场更好」有用得多**（按当季公开招聘页逐家核）：
- 偏新加坡：Squarepoint、Hudson River Trading、WorldQuant、Virtu、Akuna、Wintermute。
- 偏香港：IMC、DV Trading、Flow Traders、ExodusPoint。
- 两地都有：Citadel（其 GQS 在两地都设团队并称继续两头招）、Millennium、Point72、Tower Research 等。
- **两地都有办公室的公司，内部 transfer 是常规路径** —— 这一条会显著降低「选边」的心理成本，应当主动告诉他。
- 注意同一集团在不同城市的**亚洲最大办公室未必是同一个**：有的公司香港是亚洲最大，有的公司新加坡按人头是**全球第二大**。要逐家核，别用一个通例。

**存量与趋势必须分开讲：**
- 趋势（2026 年）：行业协会曾致信新加坡金管局，称会员中「越来越多在考虑把业务从新加坡迁往香港」，部分在做「几个月内」搬迁的谈话；驱动力是香港的 carried interest 免税。
- 存量：香港 2025 年 AUM 增长 **20%** 至 HK$42.2 万亿；新加坡约 **S$6.7 万亿**（≈ US$5.2T）——**同量级**。
- **政策时点差**：香港的 carried interest 免税**可追溯到上一税年**（先手）；新加坡的对应措施（激励税率下调、业绩奖金免税、政府种子资金、放宽 ONE Pass 薪资门槛）**要到下一税年才生效**。→ **短期先手不等于长期胜负**，别下「谁赢定了」的结论。

（口径提醒：薪酬/招聘指数来自第三方量化招聘基准站——它是唯一给出两地可比数字的来源，**量级可参考、绝对值不可当准数**；岗位城市分布来自各公司当季公开页。引用时一律标明来源性质。）

## 四、税率与生活成本（关键交叉点）
- **有效税率交叉**：新加坡累进前几档宽、减免多，**中高收入段（≈S$200–500k）有效税率低于香港**（S$200k≈8.8%；香港同级≈13.1%）；香港靠标准税率 15% 上限，只在**超高收入（>S$100 万 / >HK$500 万）**才反超。→ **别凭「香港低税」直觉下结论**。
- 内地边际最高 45%（最重）。
- 生活成本锚点：「很不错的房子」——新加坡公寓 S$160–250 万；香港港岛 700–800 呎 HK$1,000–1,600 万、好地段大户型 HK$1,500–3,000 万+（全球最贵）；上海好地段 100–120㎡ 人民币 800–1,800 万。
- 「一个人撑全家富足」门槛：新/港/沪均需年薪约 **人民币 100–150 万**（同岗位前 5–10%）。

## 五、读博：能不能边工作边读、代价多大

### 5.1 三条路性质完全不同——先分清他问的是哪种「读博」
| | 国内非全日制工程博士（定向） | 海外研究型 PhD | 国内全日制 |
|---|---|---|---|
| 要辞职 | **不用**，边工作边读 | **要** | 要 |
| 钱的方向 | 你交学费 | **学校给你钱** | 学校给奖助 |
| 金额 | 十几万–二十几万（顶尖校 0854 非全可到 24 万/生，分 3 年） | 见 5.3 | 视学校 |
| 谁出钱 | 通常单位定向委培 | 学校 / 导师课题 | 学校 |

- 国内**专业学位大类本身含博士段**（如 0854 电子信息 → 工程博士），所以「某专业代码的硕士」并不是通道的尽头。已有院校开设非全日制定向工程博士并列出具体领域（人工智能、计算机技术等），**学习形式写明非全日制**——这就是「工作后边干边读」的现实通道。
- **申请-考核制的学历栏通常只写「已获硕士学位」**，不区分专硕 / 学硕 —— **专硕不是读博的障碍**。
- **年龄基本不是障碍**：常规博士口径 ≤45 周岁，**委托培养与自筹经费的不限年龄**。他 20 出头，「将来想读」的时间维度非常宽裕。

### 5.2 海外研究型 PhD 基本不让「边工作边读」
- 商学院常**明文**排除：例如 NTU 商学院 FAQ 写明不提供 part-time、也不提供远程 PhD；NUS 商学院写明 PhD 只能全日制。
- **校级页面与院级页面口径可能相反**：学校层面可能写「可全日制或非全日制」，具体学院却只收全日制。**以学院 / 项目页为准**。
- 所以「工作后有空再读」在海外体系里等于**停产 4–5 年**，不是「有空再读」。

### 5.3 海外读博的现金流方向常被搞反
- 研究型 PhD 多为**带薪**：例如 NTU Research Scholarship 国际生约 **S$3,000/月**（2026 起），通过资格考核后上浮，覆盖学费，最长 4 年；NUS 同档。**这是收入，不是学费。**
- 所以代价不是学费，是**机会成本**。直接算给他看：`起薪 × 年数 − 津贴 × 年数`。起薪越高代价越大——顶级买方档读 4 年约少赚 **¥240 万**量级、读 5 年约 **¥300 万**；机构档约 ¥176 万 / ¥220 万；银行档约 ¥113 万 / ¥142 万（按 S$3,000/月津贴、1 SGD≈5.25 CNY）。
- 对照国内非全工程博士：学费二十万量级，但**不放弃工资**。两栏并排放，选择自然清楚。

### 5.4 结论该落在「路径与概率」，不落在「绝对高度」
- **有博士**：以研究员身份起步，**第一天就在研究梯子上**。
- **无博士**（MFE 等）：从工程 / 数据 / 风控 / 交易支持起步，**要靠实际做出来的策略申请转研究岗**——转得过去天花板相同；转不过去就停在工程线上。
- 反证也要摆（否则会答成「没博士就封顶」）：项目的官方 career paths 常明列量化研究与组合管理；且能查到**无博士做到 QR/PM 的可核实例**。（行业论坛的自述数据只能当量级参考，必须标注是自述、非统计。）
- 正确表述：**博士是更宽、被显式优待的入口；硕士走第二条门，需要更长的证明期。差别在概率与时间，不在倍数。**

### 5.5 收尾给一条他能自己验的判据
把「要不要读」换成可复核的一条：**能否独立产出一个讲得透的策略 / 因子 / 回测框架**。这条过得了，学位只是路径长短；过不了，学位也换不来岗位——因为那条梯子的通行证是「能产出 alpha」，学位只是它的代理变量。**这件事不必现在拍板**：读博的申请看的是硕研 + 工作期间留下的产出，不是起点选了哪条路；同时明说上限可以「工作几年后再补」，只是那时候要付 5.3 的机会成本。

### 5.6 博士项目的类型与门槛：名字相近，难度差一个数量级

「读博」不是一个项目类型。**先按方向分开问**，再谈可行性与上限。

**硬材料清单**（所有研究型博士共有，缺一样就是硬伤）：研究计划 / 研究经历 / 论文摘要（如有）/ **两封学术推荐人的信**（明确用来评估学术能力）/ 语言成绩。
→ **授课型硕士（含 MFE）这几样一样都给不了**：没有学位论文、没有研究导师，成绩单也证明不了研究能力。这不是「学校不好」，是**项目设计就不产出这些材料**。
→ 一手佐证：Berkeley MFE 官网 FAQ 自述——PhD 面向学术职业，**MFE 在某种程度上可视作「面向商业而非学术的职业」的博士替代品**。**MFE 是博士的替代品，不是跳板**；要跳，跳板得自己造（去读研的学校找教授做 RA，只求一封学术推荐信）。
→ 结构性推论：**研究证据必须在授课型硕士之前就造**。最省力的窗口是在**有导师、有课题组、人在学校**的那段（国内硕士期），不是在后一段。这个顺序不能颠倒。

**按方向分档（录取难度悬殊，读时要重核）：**
| 方向 | 现实难度 | 备注 |
|---|---|---|
| **数据科学 PhD** | **相对可达** | 项目常明写「interdisciplinary and open to individuals from many backgrounds」；且常是「大数据管理 / 数据工程」这条本科专业链的**自然延长线**——「对口」在这里是真的 |
| 信息系统 / 商业分析 PhD（商学院） | 中等 | 与「大数据管理与应用」本科高度对口，但**出口是学术岗**——对口的是背景，不是「做量化」的目标 |
| 金融 PhD | **最难** | 对口量化目标，但是商学院博士里最窄的一档 |
| **CS PhD** | **最不现实** | top 系录取率 well below 10%（个别校 <2%），且录取者中**相当比例已有顶会论文或强投稿**；要的是算法 / 理论深度 + 顶会产出，与「补课一年」不是一个量级 |

→ **「看着最对口」常等于「最难」**：数据背景的人看 CS 最顺，实则是要求最高的一档。选项要按**门槛**排，不能按名字的亲近度排。

**数据科学 PhD 的具体闸门**（逐条读官网，数字逐年变）：
- **GPA**：常见 3.0–3.5/4.0，且**有的项目把「能否拿资助」绑在更高的 GPA 上**（如明文写「GPA 3.5 才考虑任何形式资助」）→ 分数不够时不是「没奖学金」，是**连资助资格都没有**。
- **数学分析（real analysis）**：常列为先修。**没修过不等于死结**——官网常写「先修不全者可 provisional admission，入学后补 leveling courses」。**先查这句再判断可行性**，别看到先修就否定。
- **GRE**：多写「required」且「no exemptions apply」→ 提前排进时间表（可与考研后那段空档对齐）。
- 编程、概率统计是标配（他这块有余量，不是瓶颈）。

**两个必查的陷阱（名字像 PhD，钱的结构相反）：**
1. **低驻校 / 线上 + 按学分收费**的「专业博士」——同一类名字下，一边是全额资助的研究型博士，一边是几万美元学费的自费项目。看到名字先查**这两项**。
2. 看**是哪个系开的**：数学 / 统计系、CS 系开的 ✅；挂在「某某学院」下的新项目 ⚠️；**两系联合开设的**（如应用数学统计 + 计算机）比单一新项目靠谱。

**GPA 口径：博士申请主要看最近一个学位的成绩。** 本科排名靠后**不直接决定天花板**，真正能控的是**硕士（与第二个硕士）的绩点**。但要点破：**「只求学懂、不刷分」是保研关闭后的正确策略，对博士申请不成立**——若读博在考虑内，硕士绩点要当硬指标打。

**结论落点**：把「要不要读博」拆成「**哪个方向**的博士 + 出口是学术还是工业 + 与他的地理目标是否兼容」，再给判据。数据科学博士是少数**同时对口专业链与地理目标（当地有 research scientist / 数据科学家岗，不像买方研究岗集中在枢纽）**的方向；CS 博士看着最对口、实际最不可及。
