# 目标院系的考核细则（逐点核过，可直接用于排期）

用途：他说「我需要 X 才能过复试 / 过面试」时，先在这里对一下目的地到底怎么给分。
**所有条目都标了来源年份；招生目录每年 9–10 月发、复试方案次年 3 月前后发，用前必须重核当年版本。**

## 华东师范大学 085411 大数据技术与工程（数据科学与工程学院）

### 复试结构与给分（据该校 2024 年公布的该专业复试办法）

| 环节 | 形式 | 分值 | 备注 |
|---|---|---|---|
| 综合能力考核 | **面试** | **400** | 含专业知识、学习能力、创新能力、灵活运用知识能力、表达能力 |
| 外语能力考核 | **口试** | **100** | 语种与初试一致，考查用外语做专业与技术交流 |
| 思想政治素质和品德 | 面试 + 政审 | **合格 / 不合格**（不计分） | — |

- **复试总分 500，低于 300 分即为复试不合格。**
- **面试之前有上机考察**，其结果是面试专家评「综合能力考核」的**参考依据**（不单独计分）。
- **上机考察**：集中线下编程，语言为 **C、C++、Java 或 Python**，考查用编程解决问题的能力。

### 复试范围（据该校 2023 年复试科目表，085411 条）

1. **上机考试**——考查运用计算机编程解决问题的能力。
2. **运用专业基础知识的综合能力（口试）**，范围明列为：
   **高等数学、离散数学、数据结构、操作系统、数据库系统、分布式系统、概率论与数理统计、机器学习与数据挖掘。**
3. **外语听力、口语测试。**

### 提交材料清单（据 2024 年办法）

在籍证明 / 本科学习成绩单 / 毕业论文（设计）摘要 / **科研成果** / **获奖证明** / 专家推荐信 / 其他反映研究能力与创新潜质的材料。

### 由此推出的排期结论

- **科研成果与获奖只进材料清单，不进任何评分项。** 所以「我要一个竞赛奖牌来撑复试」是个错配——它顶多是面试谈资。
- **真正的高权重缺口是上机**：它直接支撑 400 分的面试评价，而它跟「做过项目」「打过比赛」是两种能力，需单独限时训练。
- **「操作系统」在初试（829）与复试口试范围里各出现一次**，而部分本科培养方案并不开这门课 → 一门课要填两次坑，排期时不能只按初试口径算。
- 同理，**离散数学、分布式系统**若本科未修，属复试口试范围而非初试范围，容易被整条漏掉。
- 外语口试 100 分考的是**用外语讲专业技术**，与应试英语不是同一种训练。

## 新增目标院系时的填写要求

1. 只抄**官方原文**（院系研招页 / 研究生院复试方案 / 复试科目表），第三方考研站只作定位线索。
2. 必须分清三类：**计分项** / **参考依据（不计分但影响面试）** / **不计分的材料项**。
3. 记录年份，并在本节写明「何时必须重核」。
4. 若初试与复试范围有重叠科目，单独列出——这类科目在排期里的权重被系统性低估。
