# 判断一所高校 / 一个研究生项目的真实水平

适用：用户问「X 大学什么水平」「它分数线这么低是不是很差」。核心是**把「水平」拆成可查的证据**，并解释分数线的成因，而不是直接给一个档位形容词。

## 一、分数线怎么读（最容易被问到的点）

分数线衡量的是**有多少人愿意报**，不是**能培养出什么**。三条判据：

| 观察 | 含义 |
|---|---|
| 某专业复试线 **恰好等于当年国家线**（分数与单科线都对齐） | 一志愿上线人数不足、招不满，只能按国家线放人进复试 |
| **调剂线 > 一志愿线** | 真实门槛在国家线之上；「国家线能进复试」的窗口只留给一志愿 |
| 同一校不同专业线差 60 分以上 | 冷热极不均，学校层面不能给一个数 |

补充机制（解释为什么一志愿会不满）：学校年轻/无考研口碑沉淀、名额大头给推免与夏令营、专业课自命题、体量小。

**复试权重必须一起读**：多校总成绩 = 50% 初试 + 50% 复试，另有综合素质考核；此时分数线只是入场券，材料审核与面试才是决定性的。

**博士没有分数线**：申请-考核制走材料审核 + 综合考核 + 导师双选。

## 二、分层表（决定结论的地方）

写「某校硕士什么水平」之前，先按这两轴切分：

- **学籍归属**：校本部 / 校本部学籍+研究所或企业导师的联培 / 他校学籍的联合培养。
- **实际培养单位**：导师所在机构决定真实产出与资源；同一校名下挂靠机构之间的差距，往往大于这所学校与隔壁学校的差距。

结论模板：**「入口冷、培养热」+ 分层**——顶层可对标甚至超过上一档学校，中层相当于同档普通水平，底层就是国家线水平。判断顺序永远是「哪个学院 / 哪个所 / 哪个导师 → 再谈水平」。

## 三、证据清单与出处

| 要什么 | 去哪拿 |
|---|---|
| 本体规模、师资、学位点 | 学校官网「学校简介」（在籍学生常按本科/硕士/博士分列，注意「含他校学籍」的括注；常任教授 vs 特聘教授要分开读）、双一流名单、百科 |
| 招生结构、复试线、录取规则 | 各院系研招页 + 「招生 Q&A」/「复试实施细则」（总成绩公式、初试复试权重）；**研究所发布的「接收校-所联培调剂考生通知」常直接列出「调剂专业及分数线」**，一志愿线与调剂线并列，是最好的证据源 |
| 出口 | 学校**信息公开网**的《毕业生就业质量报告》：按本科/硕士/博士分列落实率与去向结构（学术去向 vs 产业去向、行业分布、单位性质、留城比例） |
| 科研体量 | 自然指数（Share 可估人均，论文数看规模）；软科世界大学学术排名（吃绝对量，小体量学校被低估）；软科/ABC 中国大学排名 |
| **学位授权点（谁有资格授什么学位）** | 信息公开网 / 研究生院的《硕士、博士学位授权点》公告：逐条列出**博士一级学科 / 硕士一级学科 / 博士专业学位类别 / 硕士专业学位类别 + 授权日期**——回答「有多少学科专业」最权威也最快的一处，比翻招生目录全；授权日期还能看出扩张节奏 |
| **当年实际招生专业** | 研招网的《硕士招生专业目录》（招生单位 × 学科 × 研究方向 × 学制/考试科目）；各院系的博士招生细则；本科看本科招生网的《招生常见问答》 |

**抓取技巧**：官方 PDF 的可靠路径是**先在栏目页用 curl 抓 HTML、正则取出 `_upload/article/files/.../*.pdf` 链接，下载到本地再交给 read_file**（自动抽文本，比网页抽取后端稳）。web_extract 对这类站点常超时或返回后端错误——失败了就换这条路，不要放弃该来源。

两个解析陷阱：① 就业质量报告 PDF 取不到时，**去找同一份报告当年的新闻稿**（教育在线、上观新闻、学校官微转载），数字同源且是结构化文字，更好取；② **招生专业目录 PDF 的表格列在抽取后会错位**（招生人数串到别的专业上）——只取**学科名与研究方向**，**绝不引用错位后的数字**。web_search 偶尔返回后端错误，**用完全相同的 query 重试一次**通常即成功（后端会轮换）。

## 四、口径题：问「多少个学院 / 多少专业」时，先分口径

同一所学校有**四个互不相等**的数，混用必答错——分别给，不让一个数顶替：

| 口径 | 含义 | 典型差异 |
|---|---|---|
| 教学学院 | 真正的院级建制（常「大学院制」，学院下不设系） | 最少，往往只有个位数 |
| 招生单位 | 实际招研究生的单位（学院 + 独立研究所） | 比学院多一两个 |
| 研究所 / 中心 / 书院 | 挂在官网「院所设置」下但不是学院（虚体科研平台、通识教研部、本科生书院） | 十余个，官方常合并成「学院、书院、研究院所、科研中心等 N 个」 |
| 本科专业 | **专业设置口径 ≠ 当年招生口径** | 简介写「本科专业 12 个」而当年只按 10 个招录（部分停招或只在少数省份投计划）——两个数都要写，并解释差异 |

研究生学科同样要分开列：**一级学科**与**专业学位类别**是两类（写成「博士 6 个一级学科 + 3 个专业学位类别、硕士 9 + 5」）。

## 五、常见误判

- **用学校排名代替具体院系/导师**：总量榜对小编制学校结构性低估，对大体量学校高估，两边都不能用来定单个人所在课题组的档。
- **把本科入口的含金量迁移到硕士身上**：本科若走提前批/开放日/综合评价，入口极卷；硕士若走统考/调剂，入口可能压在国家线——两者不矛盾，也不能互相证明。
- **把「联培」当成同质标签**：校本部学籍不等于校本部培养，真正决定训练质量的是日常在哪个组、哪个 PI。
- **只看落实率不看结构**：落实率 90%+ 只说明有去向；博士 45% 博后 / 10% 教职 / 37% 企业这类结构数据才说明出口性质。
- **拿「分数线低」直接推「水平低」**：先看是否等于国家线、调剂线是否更高——多数情况下结论会反过来。
- **无视统计口径**：就业质量报告多只统计**授予本校学位**的毕业生，他校学籍的联培生不在其内——引用任何比例前都要标注这一点，否则会把「看不见的那部分」当成「不存在」。
- **用「学校招牌的社会认知度」替代「实际培养强度」**：年轻研究型学校在科研圈 / 特定研究所以内的认可度可以远高于其校名的社会认知；反之在选调、部分国企与有「第一学历/校名」偏好的单位，新校名不占便宜——两个方向都要说，只说一头就是骗人。
