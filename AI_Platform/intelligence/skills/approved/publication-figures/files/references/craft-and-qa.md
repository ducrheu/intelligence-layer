# 图的质量标准与交付清单

机械检查（`audit_fig` / `critique.py`）只是**地板**：它保证这张图不会被一眼看出是"默认样式"。
真正的天花板是下面四条判断，必须人工过一遍，看图和写代码的人不是同一个人时尤其重要。

## 一、四轴质量标准（每张图必过）

1. **深度（Depth）**——图在回答 *为什么 / 所以呢*，不是"我画了数据"。机制、阈值、临界点要标出来
   （例：标出 $t_{1/2}$、失效阈值、显著翻转的位置），而不是让读者自己从曲线里猜。
2. **优雅（Elegance）**——一张图一个主张、一个主角面板。删掉任何一个不参与论证的面板后图还能站得住，
   那它本来就该删。
3. **不可指摘（Unimpeachable）**——不确定性有表示且**说明了含义**（CI / SD / SEM）、`n` 写明、
   脚本能重跑出同样的图（数据来自文件、随机种子固定）。
4. **一眼是论文（Visible gap）**——版式与字体达到期刊观感：尺寸即最终尺寸、字体统一、线宽克制、
   没有默认色板与多余装饰。

一句话闸门：交给最挑剔的审稿人，如果他还能说出一句"不错，但是……"，这张图没做完。

## 二、反模式清单（出现即改）

**配色**：`jet/rainbow`；`tab10/Set1` 等默认色板；红绿单通道编码；同一颜色在不同面板指不同东西；
超过 7 类还硬塞图例。

**坐标轴**：四边框全留 + 灰底网格（seaborn/ggplot 默认外观）；轴脊比数据线还粗；刻度朝内压住数据；
柱图不从 0 起（除非是点图/棒棒糖的等价物）；对数轴不标注。

**图例**：浮在数据上遮住点；带边框和底色；条目重复；能用直接标注却用图例（读者视线要多跳一次）。

**排版**：不同面板字号不一致；在显示尺寸下的字号看着行、缩到印刷尺寸后 <5pt（IEEE <8pt）；
中英文字体混搭无理由；文字压在曲线/柱子上。

**导出**：只给 72dpi 截图；把位图塞进 PDF 当"矢量"；文字转曲（不能改字，排版会退）；
PNG 当正文主件。EPS 不支持半透明——置信带在 EPS 里会变实心块，要 EPS 就把带改成 hatch 或改用 PDF。

**统计表达**：误差棒不说明是 SD/SEM/CI；只给星号不定义阈值（要在图注写 `*p<0.05, **p<0.01`）；
用柱图掩盖分布（样本少时必须叠点）；不写 `n`；把不显著说成"有趋势"。

**中文场景特有**：汉字与 `$公式$` 写在同一条 text 里 → 汉字变方框（必须 `pf.mixed_text()`）；
用 Droid Sans Fallback 之类的兜底字体当正文（要装 Noto Sans SC）；全角标点混排英文数字造成字距怪异。

## 三、多面板的 composing 规则

- **先写叙事**：`(a)` 现象 → `(b)` 机制 → `(c)` 定量验证 → `(d)` 消融/稳健性。
- **主角面板更大**：2×2 网格里可以给关键面板 `width_ratios`/`height_ratios` 加宽，不要四个等大平均用力。
- **共享轴标签**：同列共用 y 标签（`sharey=True` + 只在最左列写标签），省空间也减少重复。
- **共享图例**：整个图一个图例，放在图外右上或底部（`pf.legend_outside`）。
- **对齐**：面板宽高一致、坐标轴基线对齐；`constrained_layout` 会自动处理大部分重叠。
- **检查顺序**：先看缩略图（`_gallery.png` 那种对照图）判断整体节奏，再逐面板看细节。

## 四、图注（caption）写法

**图注陈述结论，不陈述内容。**

- ✗ "图 3 展示了 X 与 Y 的关系。"
- ✓ "Y 随 X 线性下降（斜率 −0.42，95% CI [−0.48, −0.36]，$n$ = 184）；超过虚线阈值后趋势反转。"

四段结构（1–4 句）：
1. 头条结论（与脚本里 `claim=` 一致）；
2. 只有不显然的元素才解释（"阴影 = 95% CI；点 = 单次重复"）；
3. 统计信息：检验方法、`n`、误差定义；
4. 多面板的 `(a)… (b)…` 分述。

规则：每个符号/颜色/线型/误差定义都要能对上；正文引用写"如图 3 所示""图 3a"，**不要**写"如下图"
（浮动位置会变）；单位与轴标签一致；显著性优先给精确 `p` 值，用星号必须定义阈值。

## 五、交付前清单（逐条打勾）

- [ ] `pf.setup(<目标预设>)` 只调一次；没有逐图改 rcParams
- [ ] 图宽 = 目标列宽（单栏/通栏），高 ≤ 页深上限；未在导出后缩放
- [ ] 所有字号 ≥ 预设下限（`audit_fig` 无 ✗）
- [ ] 矢量主件（PDF/SVG）+ 300dpi PNG 都在；PNG 实际像素与 mm×dpi 对得上
- [ ] `critique.py` 无 FAIL
- [ ] 色盲/灰度可辨；颜色数 ≤7；红色只用于一处强调
- [ ] 轴标签带单位；柱图从 0 起；误差含义与 `n` 写在图上或图注里
- [ ] 面板标签齐全且位置一致；共享色标显式给了 `vmin/vmax`
- [ ] 数据来自文件、随机种子固定（`pf.seed(0)`），脚本可一键重跑
- [ ] 每张图在正文里被解释过（2–3 句），不是装饰
- [ ] `figure_manifest.csv` 里登记了 `claim` 与文件路径
