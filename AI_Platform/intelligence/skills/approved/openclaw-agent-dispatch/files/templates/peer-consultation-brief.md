# 跨 runtime 顧問型派活：訊息骨架

用途：請 peer（或 peer 的專家 sub-agent）對一件具體的事給意見，要能換回**具體反駁**而不是附和。
複製後改寫：把每個 `<>` 換掉，刪掉不相關的小節，**不要**壓成一段閒聊。
